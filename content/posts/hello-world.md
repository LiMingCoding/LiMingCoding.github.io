## 一段示例代码

技术博客少不了代码块，这是一段示例：

```python
def fib(n: int) -> int:
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

# 算到第 10 项
for i in range(10):
    print(i, fib(i))
```

## 一些准则（写给自己的）

- **写完就用上**：能跑的就跑一下，能用上的就贴实战场景。
- **不抄书**：只写从自己视角能讲清楚的部分。
- **错了就改**：技术债难免，发现错就立刻修正，再回头补一篇勘误。
